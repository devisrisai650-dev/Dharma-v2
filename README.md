# Dharma v2
Run `python -m pip install -r requirements.txt` then `python upgrade.py`.
Shop: http://localhost:8000 ; verification: http://localhost:8001.
Shared SQLite database; admin token printed in terminal. Three six-stage illustrated story concepts: DH-00001, DH-00016, DH-00025. All data is fictional; no real certification or payments. QR codes use verification base URL; localhost is not accessible from another device. Configure DHARMA_SHOP_URL and DHARMA_VERIFY_URL for deployment and adapt server binding behind a secure reverse proxy. Demo only, not production hardened. SVG designs are editable concept sketches. Existing order workflow is on passport portal.

V3: Three bundled 24-second silent MP4 concept animations; purchase pages for all 25 designs. Run python upgrade.py. Physical sellers are unconfirmed; orders are demo only. Optional media regeneration: python make_media.py (requires Pillow, CairoSVG and ffmpeg).
